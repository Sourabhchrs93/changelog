dbt Power User now has Altimate Code chat actions on every SQL and YAML file. Inline codelenses for **Execute**, **Explain**, **Optimize**, **Document**, and **Review** sit at the top of each file, and the same actions appear in the editor and explorer context menus and the editor title bar. The Review action only surfaces when git detects unstaged changes, so it's quiet on clean files.

When a query fails in the Query Results panel, the new **Troubleshoot with Altimate Code** button opens an Altimate Code chat with the compiled SQL and error message already in the prompt — one click from "this query errored" to a working conversation about what went wrong.
