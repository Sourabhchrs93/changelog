Cortex Code CLI joins the AI Services cost view. A new usage history pipeline pulls Cortex Code CLI events from Snowflake, ingests them into the AI Services tables, and surfaces them with the same summary, breakdown, and filter affordances as Cortex Functions, Cortex Agent, and Snowflake Intelligence.

Same data model, same filters — so cost attribution across all four Cortex surfaces lines up in one consistent view.
