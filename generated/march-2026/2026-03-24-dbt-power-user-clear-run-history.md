The Run History view in dbt Power User picks up a trash-icon "Clear Run History" button on its title bar. Click it and the entire in-memory run history clears in one go, so a long debugging session doesn't leave the panel cluttered with stale entries.

The state is per-workspace; reopening the panel after a clear starts you with an empty list.
