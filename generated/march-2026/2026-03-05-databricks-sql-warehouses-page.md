Databricks tenants get a dedicated SQL Warehouses page that mirrors the cost-trends-plus-list layout used elsewhere in the app. A trends chart shows daily SQL Warehouse spend over time, and the warehouse list below supports sorting, filtering, and pagination so you can drill from "where did this spike come from" to a specific warehouse in a few clicks.

The page is gated by tenant — Snowflake-only tenants are unaffected, and Databricks tenants pick up a new sidebar link automatically.
