The VS Code Altimate MCP extension now ships a first-party chat panel for Altimate Code, opened from the editor title bar or the command palette. Each panel shows a session switcher, an agent picker, and a streaming-aware message list that renders Markdown, code blocks, and rich UI elements as they arrive.

The same chat panel is what the April release polished into instant-open mode and added a token-usage indicator to. The April 2026 polish entry continues from here; this is the launch.
