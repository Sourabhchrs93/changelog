The Databricks Clusters page picks up a Workspace column filter alongside the existing Cluster, Source, Driver Node, and Worker Node filters — useful on multi-workspace tenants where the same cluster name shows up across workspaces.

Active filters are now visible at a glance above the table instead of buried in each column dropdown, and the cost-trend tooltip formats values as currency rather than raw numbers, so a $1,234.56 day no longer reads as "1234.56".
