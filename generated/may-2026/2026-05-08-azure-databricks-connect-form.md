Connecting an Azure Databricks workspace now has a dedicated path in the connections UI. Submit the form once for a standard Azure Databricks workspace, or use the separate Private Link variant for workspaces fronted by Azure Private Link, and the platform persists each connection as its own entry — multiple Azure Databricks workspaces per tenant are supported side by side.

The connections sit alongside the existing AWS and GCP Databricks forms, so multi-cloud Databricks deployments now configure under one roof.
